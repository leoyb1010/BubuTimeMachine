# 2.14.0 · 每一刻，都稳稳收好

版本：iOS / HarmonyOS `2.14.0 (2026090801)`；后端 `2.14.0`。

## 本轮升级

- 双端使用 `(updated,id)` 分页，覆盖同毫秒批量写入、编辑导致排序变化、墓碑和坏响应；首次升级重新核对历史窗口。
- iOS 冻结 V1 模型，新增 V2 同库同步进度；较早、缺少入园字段的旧库先安全规范，再执行版本迁移。
- iOS 升级前通过 SQLite backup 保留包含 WAL 的保护副本，并由 App/Widget 共用跨进程迁移锁。
- 保存或读取失败不再被解释为“记录不存在”；删除先提交数据库，再清理文件，保留有本地改动的子记录。
- 同步中心展示逐类核对结果；首页日期、身份卡和导航使用可读文字色；记录页直接进入操作与输入。
- 鸿蒙补齐入园日期、过敏和健康备注的持久化、同步及编辑；未编辑的新字段不会清掉远端值。
- 鸿蒙把数据库和核心服务异常交给明确的错误边界；替换旧图片编码、通知授权和减少动态接口。
- 鸿蒙升级前保留 RDB 副本；DDL 和表结构校验使用同一个 Transaction，避免读连接看到旧结构而错误阻断启动。
- 胶囊记住加密版本并拒绝 v3 降级；后端同样禁止降低 cryptoVersion；字节转换按有效内容复制。
- 后端归属迁移只更改 familyId，原有账号、正文、媒体引用、时间戳及密码保持不变；检索索引与待上传批次同步迁移归属。
- 备份与通知服务恢复；公开 CI 新增真实 PocketBase 迁移、隔离和原子摄取测试。测试数据库不再自动弹出浏览器。

## 回退边界

生产切换前的数据库、两份侧库、环境配置和 LaunchAgent 原件都保存在服务器专用升级备份目录。
公开服务恢复后不使用旧数据库覆盖新增记录；必要时回退代码并保留向前兼容的数据库与家庭归属。
iOS 已进入 V2 后不直接安装旧版覆盖，新版本保留原始数据库保护副本供隔离恢复。

公开发布物包含源码与无签名 HAP；设备专用的签名 HAP、开发签名 iOS 包和个人签名材料保留在本机，不上传公开仓库。

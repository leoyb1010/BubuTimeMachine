# iOS / iPadOS 2.12.1 二次生产审计

> 日期：2026-08-29
> 范围：iPhone + iPad；不扩建 watchOS、HarmonyOS。
> 基线：`main` 的 2.12.0；目标版本：2.12.1。

## 结论

本轮不是继续堆功能，而是对 2.12.0 的系统搜索、导航、端侧语音、首页统计、上传边界和测试可信度做对抗式复核。已确认的问题均修复并补回归测试；当前 iOS 26 正式路径可发布，iOS 27 专属 API 仍以安装 Xcode 27 后的 shadow build 为准。

当前生产成熟度：**84 / 100，可发布但有设备侧门禁**。分数上限来自本机只有 Xcode 26.6，且本轮没有在真实 iPhone/iPad 上验证 Spotlight 系统索引、签名和后台行为；模拟器的产品路径与视觉验证已通过。

## 已修复

| 等级 | 问题 | 修复与证明 |
|---|---|---|
| P0 隐私 | 关闭 Spotlight 时，仍在运行的索引任务可能晚于清理完成并重新写入 | 索引与删除严格串行；关闭会等待前序任务并清空全部索引；新增陈旧 ID 差集测试 |
| P1 正确性 | 归档/删除后的旧记录可能残留在 Spotlight | 持久化上次索引 ID，按新旧差集删除；查询明确排除归档记录 |
| P1 导航 | 快速记录状态可能残留，随后打开时光 deep link 被错误覆盖 | 每次解析路由都同时重置或设置 quick-capture 状态；新增路由回归 |
| P1 稳定性 | SpeechAnalyzer 启动抛错时，结果监听任务可能悬挂 | 用作用域清理保证所有退出路径取消监听 |
| P1 安全 | multipart 文件名可携带换行、引号或路径字符；失败时可能残留临时文件 | 文件名统一净化、限制长度；错误路径清理临时 body；新增独立测试套件 |
| P1 数据 | 首页照片数包含已归档记录，同步回旧数据后统计不刷新 | COUNT 排除归档关系；同步完成与刷新后重算；新增归档统计测试 |
| P2 边界 | 2 月 29 日在非闰年可能被日期归一化成 3 月 1 日 | 构造后校验月日，不把错误日期算入“那年今日” |
| P2 测试 | UI 测试复用模拟器磁盘数据库，可能受旧数据污染 | 所有 XCUITest 使用独立内存容器；覆盖 iPhone/iPad 与 Spotlight 开关 |
| P2 体验 | Toggle 与菜单行仍显示右箭头，语义像导航；说明过长 | 开关/菜单移除箭头并压缩文案，导航行保持系统预期 |
| P2 CI | GitHub Actions 使用旧 Node 运行时并产生弃用告警 | 官方 checkout/setup-node/setup-python 更新到当前 major |

## 验证证据

- 静态：Swift 严格并发编译、`xcodebuild analyze`、plist 校验、重复源文件检查、`git diff --check`。
- 单元：157 项 / 27 套件，0 失败。
- UI：iPhone 5 项（iPad 专属项按预期跳过）、iPad 5 项，0 失败；使用独立内存数据。
- 视觉：iPhone/iPad 首页、设置、快速记录、时光 deep link 与 iPad 横屏均已截图复核；家庭真实数据不写入仓库。
- 构建：Debug clean 与 Release 构建均要求零项目 warning/error。

## 尚需真实设备完成的门禁

1. 在真实 iPhone 打开 Spotlight 开关，确认系统搜索可发现记录；关闭后确认结果完全消失。
2. 验证 Universal Link / App Entity 从系统搜索冷启动直达正确时光。
3. 锁屏、切后台和弱网下验证照片后台上传与临时文件回收。
4. 安装 Xcode 27 后执行 shadow build、iOS 27 模拟器截图和至少两版 TestFlight 家庭圈回归，再启用任何 iOS 27 专属代码路径。

这些门禁不阻塞 2.12.1 的 iOS 26 路径，但没有真实证据前，不把“iOS 27 全能力完成”写成已完成。

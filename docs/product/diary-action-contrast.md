# Diary action color roles

Pastel primary colors remain decorative. The generated diary's white-text action uses the existing actionFill role; actionable text uses textAccent. A current native capture of coral primary RGB242,140,158 measured2.328:1 against white, whereas the existing semantic roles are tested at4.5:1. This change affects only diary action presentation, not request ownership, cancellation, save or selection semantics. Actual post-change screenshots must still be inspected; semantic token tests are not full-view accessibility certification.

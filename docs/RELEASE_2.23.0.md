# 2.23.0 测试版候选

候选版本：`2.23.0 (2026102101)`。开发基线为 `origin/main d99c63e`；已核对它与现有服务器 2.22.0 的运行代码一致。此次完成源码接入和发布准备，已生成App Store分发IPA；尚未切换生产服务或上传TestFlight。

## 本次变化

- iPhone 保存到照片库的幼儿园材料，经现有第二大脑 iCloud/Gemini 流程成为教学候选；学习 worker 自动做完整音轨解析、按日期归档和课程草稿。
- 题目使用可回查的教师原声及对应画面；颜色组合保留完整答案。家人核对授课日、原声、图像和答案后才开放；转写修订和日期变化撤销旧确认。
- 按日期学习、近7天/30天重温、按账号和孩子隔离的互动记录。关闭原生课程页后，命名 WebKit 持久存储保留离线队列。
- 已人工确认归属的素材可自动进入时光；历史模型人物匹配仍为候选。导入去重，删除/归档不复活，不覆盖家人正文。
- 时光支持类型、拍摄日期、来源筛选与三种排序；解析检索返回真实已同步记录，并区分无结果、未同步与网络失败。
- 修复视频时长/哈希准备、远端播放失败重试、本地原片缺失恢复；详情页支持解析和时间码跳转。
- 修复 iPad 学习入口空白区域不响应点击。五个分发 bundle 补齐所需隐私清单；本轮没有改变 SwiftData `@Model`。

## 给测试者的重点

1. 从群聊保存一段老师视频，等iCloud/第二大脑完成后，查看候选日期与原片。再次保存同片，确认新的出现记录没有被吞掉。
2. 核对每道原声题。确认不会先播放介绍；南瓜等后半段内容也存在；“Yellow and green”作为整个答案。
3. 改一段转写或授课日期，确认旧课程停止开放，新版本重新核对；旧浏览器页面不能覆盖新版。
4. 在孩子课程里选择、听示范和暂停。断网产生互动记录后关闭页面，重开同账号仍能补传；切账号/服务不混入旧记录。
5. 在时光页使用类型、日期、来源和排序；删除/归档自动导入记录后，它不应再次出现。
6. 对视频查看解析并点击时间码；远端链接过期、原片未下载和服务不可用分别有可恢复状态。

## 发布门槛

- 全新克隆可以执行 `harmony/scripts/build-local.sh` 生成 unsigned HAP。
- HarmonyOS CI 至少运行仓库卫生、能力矩阵和静态契约检查；正式构建由带 DevEco 的受控 runner 执行。
- P0 全部具备自动化回归；关键用户路径具备真机截图、日志和跨端数据证据。
- 不允许 Mock、无跳转入口或“页面存在即完成”计入追平。
- 签名材料、账号和家庭数据不得进入 Git 历史或构建日志。
